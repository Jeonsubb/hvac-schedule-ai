## 권고

1. 최신 버전에서 규칙만 / 단일 LLM / 복수 에이전트의 동일 입력 비교. 비용·지연·결정 품질·제약 위반·수치 근거를 함께 측정한다.
2. AI 후보 채택률 대신 규칙 최선 후보 대비 엄격한 개선률을 제시한다. 동일 설정과 동점은 별도 집계한다.
3. 핵심 데모를 비정형 입력 → 상황 해석 → 도구 계산 → 변경안·승인으로 묶는다. 음성은 같은 운영 도구의 접근 수단으로 설명한다.
4. API, Voice, 비동기 Worker 분리를 우선한다. 작업 증가 시 AI/Planning/Weather로 추가 분리한다. 공통 계산 모듈은 재사용한다.
5. 인증 목업, 실설비·실측 미연동은 상용화 과제로 명시한다. AI 장애 시 fallback은 생성형 AI 성공과 구별한다.

이번 검토에서는 제품 코드를 수정하지 않았다.
