- 규칙 기반은 추운 아침에 10분 선행 가동으로 설정온도에 닿지 못해서 수업 시작 시 저온이 잦습니다. AI는 열모델로 필요한 선행 시간을 계산하므로 이 문제가 거의 없고, 그 대가로 예측 기동 단계에서 전력을 조금 더 씁니다. 날씨 판단과 재실 감지가 그보다 많이 줄입니다.
- **실외기 용량 제약(v11)**: 3층 실내기 정격 합(64.8 kW 난방)은 실외기(45 kW)보다 큽니다. 시뮬레이터는 같은 실외기의 요청 열량 합이 용량을 넘으면 비례로 줄입니다. AI 계획기는 강의실마다 "실외기를 나눠 쓸 때 기대할 수 있는 출력"(3층 69%, 4층 A 82%, 4층 B 85%)과 60% 저부하 예열 중 예측 전력이 적고 시간 안에 도달하는 쪽으로 예열합니다.
- **재실 감지(v12)**: 강의실 재실 센서(PIR·CO₂) 또는 출결 시스템 연동을 가정합니다. 사람이 없는 상태가 10분 이어지면 끄되, 같은 강의실의 다음 수업 30분 전에는 다시 켜서 예열을 확보합니다.
- 피크 상한을 둔 기동 분산은 향후 과제입니다.

## 2. 정합성 검증

- 이상 주입을 끈 학기 전체 실행에서 계획 검증은 100%였습니다. 실행 검증 불일치는 2건이었고, 모두 전날 예보와 실제 날씨의 차이로 수업 시작 시점 온도가 쾌적 범위를 0.2~0.5 ℃ 벗어난 사례였습니다(9/4 고온, 11/12). 이후 피드백 보정이 수업 중 온도를 회복시켰습니다.
- 이상 주입을 켜면 검증 화면이 무단 휴강(재실 없음 → 10분 후 자동 정지), 수업 후 수동 가동(빈 강의실 감지 → 자동 정지), 명령 실패(재전송 복구), 예보 오차(피드백 보정)를 각각 다른 상태로 구분해서 보여줍니다.
- 테스트 `test_no_anomaly_day_validates_fully`가 이상 주입 없는 날의 일치율 100%를 확인합니다.
