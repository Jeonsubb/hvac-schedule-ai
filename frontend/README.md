# ThermoPlan 프런트엔드

부산대학교 IT관(3층 306·307·309·310, 4층 405–410) 시설 담당자를 위한 **스케줄 기반 냉난방 자동 운영 AI** 웹 화면입니다.
강의 시간표·이벤트·기상 예보로 만든 강의실별 운전 계획, 실행 검증, 4가지 운전 전략(고정·수동·규칙·AI) 비교를 한눈에 보여 줍니다.

## 실행

```bash
cd frontend
npm install
npm run dev        # http://localhost:5173  (/api → http://localhost:8000 프록시)
npm run build      # 타입 검사(tsc -b) + 프로덕션 빌드 → dist/
npm run preview    # dist 미리보기 (같은 /api 프록시)
```

- 백엔드(FastAPI)가 `http://localhost:8000`에서 실행 중이어야 합니다. 모든 API 호출은 상대 경로 `/api/...`를 씁니다.
- 프로덕션 배포 시에는 `dist/`를 정적 호스팅하고 `/api`를 백엔드로 라우팅하면 됩니다(CloudFront 등).
- 화면은 1280px(노트북 시연 화면) 기준으로 맞췄고, 1920px 이상에서는 코파일럿 패널이 본문 옆에 고정됩니다. 1024px 미만에서는 사이드바가 상단 탭으로 바뀝니다.

## 기술 스택

Vite 8 · React 19 · TypeScript(strict) · Tailwind CSS v4 · react-router-dom 7 · Apache ECharts 6(`echarts-for-react`) · lucide-react · react-markdown + remark-gfm

## 화면 구성

| 경로 | 화면 | 내용 |
|---|---|---|
| `/` | 운영 현황 | 기준 시각 배너(실시간/대체 기준, `?at=YYYY-MM-DDTHH:MM`로 과거·미래 재현), KPI(오늘 AI 전력·고정/규칙 대비·쾌적·정합성), IT관 3F·4F SVG 평면도(가동/송풍/정지, 실내온도, 진행 강의, 실외기 그룹), 외기 날씨(기상청 초단기실황·단기예보), 실외기 부하, 오늘 타임라인(강의 vs AI 실행, 현재선)과 시간대별 전력, AI 판단·자동 조치 피드. 강의실을 누르면 상세 서랍. |
| `/schedule` | 스케줄·타임라인 | 9–12월 달력(강의 수, 고정 대비 AI 절감률 색 단계, 공휴일, 이상 표시, 미래=예상) + 일자 요약(전략별 kWh·요금·쾌적, 시간대별 전력). 10개 강의실 Gantt(07:00–23:30): 강의 레인, 선택 전략의 계획(옅은 띠)·실행(진한 막대, 송풍 구분), AI 판단 마커 툴팁, 두 전략 겹쳐보기. 강의실 상세 서랍: 실내온도(전략별)·외기·쾌적 범위·전력 추이, 강의별 검증, AI 판단 근거, 설비 On/Off 이력, 운전 계획 CSV. URL 파라미터 `date`, `s`, `o`, `room` |
| `/validation` | 정합성 검증 | 검증 방법 한 줄 설명, 학기~오늘 KPI(정합성·계획 반영률·검증 강의·자동 조치·확인 필요), 일별 자동 조치/확인 필요 막대(클릭 → 날짜 선택), 이상이 있었던 날 목록, 선택 일자의 강의별 상태·메모·실행률·시작 온도·쾌적(상태 그룹·강의실 필터) |
| `/energy` | 절감 효과 | 오늘까지/학기 전체(예상) 범위 전환, 대표 수치(고정 대비 절감률), 전략별 카드(kWh·원·tCO₂·최대 kW·쾌적·불쾌 누적), 일별 전력량+외기온도(축 분리 소형 다중), AI 누적 절감, 전력 vs 쾌적 산점도, AI 판단 유형별 횟수, 강의실 재배치 권고(학사 부서 검토용, 인쇄) |
| `/data` | 일정·데이터 | 강의 DB(검색·강의실·요일 필터, 인원 추정 배지, 주간 시간표 보기) · 시간표 가져오기(CSV/XLSX/JSON 즉시 비교, 이미지/PDF는 AI 판독 작업 폴링 → 내용 기준 비교 → 반영) · 이벤트(자연어 → AI 해석 → 수정 가능한 양식 → 등록 → 등록 전/후 비교, 목록·삭제) · 변경 기록 |
| `/settings` | 운영 규칙 | 규칙·설정온도·쾌적 범위·AI 한계·비교 기준·현장 이상 시뮬레이션 편집 → `/api/whatif` 미리보기 → 저장/기본값 복원(확인 창), 설비 표(가정값 배지), 시간대별 요금(한전 교육용(을) 고압A 선택I, 2023-05-16 게시본), 탄소 배출계수(0.4173 kgCO₂/kWh) |
| (모든 화면) | AI 코파일럿 | 상단 버튼으로 여는 오른쪽 패널. 추천 질문, 실행 중 도구 단계(한국어 라벨) 실시간 표시, 마크다운 답변(표), 시뮬레이션 결과, 규칙 변경 제안 카드(적용 → 확인 → `PUT /api/settings`), 일정 초안 카드(수정·등록 → `POST /api/events` → 전/후 비교). 대화는 브라우저 세션에 보관 |

## 색과 차트 규칙

- 전략 색은 모든 화면에서 같습니다: 고정 `#52514e`(회색) · 수동 `#eda100`(호박) · 규칙 `#2a78d6`(파랑) · AI `#1baf7a`(청록). 색약 시뮬레이션(OKLab ΔE) 검증을 통과한 조합이며, 범례와 직접 라벨을 함께 씁니다.
- 상태 색(정상 초록 · 자동 조치 호박 · 확인 필요 빨강)은 항상 아이콘+글자와 함께 표시합니다.
- 이중 y축을 쓰지 않습니다. 외기온도처럼 단위가 다른 값은 x축을 공유하는 아래 칸에 따로 그립니다.
- 주요 차트에는 `표` 버튼으로 같은 데이터를 표로 볼 수 있습니다.
